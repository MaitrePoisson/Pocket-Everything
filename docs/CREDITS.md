# Crédits

- Code, modèles, textes et langues (en_us, fr_fr) : originaux, écrits pour ce projet.
- Logo du projet : fichier fourni par l'utilisateur, utilisé tel quel (`docs/images/logo.png`) ; `logo.png` (512 px, liste des mods) et `pack.png` (128 px, icône du pack de ressources) dans `src/main/resources/` sont de simples redimensionnements générés par `tools/make_logo.py`.
- Aucune autre texture, musique, son ou image tierce. L'objet n'a pas de texture propre : son rendu est le modèle de la créature capturée, fourni par Minecraft lui-même au moment de l'exécution.
- Dépendances : Fabric Loader (Apache 2.0) et Fabric API (Apache 2.0) et Minecraft (Mojang), non redistribués dans le jar.
- Outil de construction : ModDevGradle, JUnit 5.
